# Blipmap · sitio e información legal

Páginas públicas de **Blipmap**, una aplicación de minimapa y HUD de conducción para Android.

- `index.html` — portada
- `privacidad.html` — política de privacidad
- `terminos.html` — términos y condiciones de uso

Se publican con GitHub Pages en <https://adrianaceitunodecastro.github.io/blipmap/>. La política de
privacidad es además la URL que figura en la ficha de Google Play, así que **este repositorio debe
seguir siendo público y la ruta de los ficheros no debe cambiar**: si se mueven, el enlace de la
ficha y el de dentro de la app dejan de funcionar.

El código fuente de la aplicación no está en este repositorio.

Al editar cualquiera de las dos páginas legales, actualiza también la fecha de «Última
actualización» del encabezado.
